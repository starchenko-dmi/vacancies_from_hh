# 🚀 vacancies_from_hh: парсер и аналитический инструмент вакансий hh.ru

**vacancies_from_hh** — это Python-проект для автоматизированного сбора, интеллектуальной фильтрации и анализа вакансий с платформы hh.ru.  
Сервис получает актуальные данные через официальное API, нормализует «битые» значения зарплат, убирает дубликаты и выдаёт отсортированный топ релевантных предложений.

Проект возвращает структурированные данные и сохраняет их в JSON, поэтому его можно легко использовать как backend-часть для веб-страницы, Telegram-бота или расширить до полноценного CLI-дашборда.

---

## 🚀 Возможности проекта

### 🔍 Сбор и обработка данных
- **Интеграция с API hh.ru:** Получение до 100 актуальных вакансий по поисковому запросу за один запрос.
- **Умная аналитика зарплат:** Автоматический расчёт средней зарплаты (`salary_avg`) даже при неполных данных (указано только «от» или только «до»), что позволяет математически корректно сравнивать предложения.

### ⚙️ Фильтрация и хранение
- **Гибкая фильтрация:** Поиск ключевых слов (hard skills) непосредственно в тексте описания вакансии.
- **Дедупликация:** Сохранение в JSON-файл с автоматической проверкой на дубликаты по URL при добавлении новых записей.
- **Интерактивный CLI:** Удобный консольный интерфейс для ввода параметров поиска и просмотра структурированных результатов.

## 🏗 Архитектурные решения

1. **Абстракция и расширяемость (SOLID)**  
   Использование абстрактных базовых классов (`BaseVacancyAPI`, `BaseSaver`) через модуль `abc`. Это позволяет в будущем добавить новые источники (например, SuperJob) или хранилища (PostgreSQL, CSV), не меняя бизнес-логику приложения.

2. **Оптимизация потребления памяти**  
   В модели `Vacancy` использован атрибут `__slots__`. Это критически важное решение для снижения расхода оперативной памяти при одновременной обработке и сортировке сотен объектов.

3. **Нативная сортировка через магические методы**  
   Реализация методов сравнения (`__lt__`, `__gt__`, `__eq__` и др.) в классе `Vacancy` на основе `salary_avg` позволяет использовать стандартную функцию `sorted()` Python. Это делает код чище, выразительнее и идиоматичным.

4. **Отказоустойчивость и строгая валидация**  
   На этапе инициализации объекта проверяются типы данных и формат URL. Метод `cast_to_object_list` использует конструкцию `try-except` для безопасного пропуска некорректных записей от API, предотвращая падение всего приложения из-за одного «битого» ответа.

## ⚙️ Установка и настройка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/starchenko-dmi/vacancies_from_hh.git
cd vacancies_from_hh
```

### 2. Установить зависимости

Рекомендуется использовать виртуальное окружение:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows)
venv\Scripts\activate

# Активация окружения (macOS / Linux)
source venv/bin/activate

# Установка необходимых зависимостей
pip install requests pytest
```

### 3. Подготовка к работе

Дополнительная настройка не требуется. Файл `vacancies.json` для сохранения результатов создаётся автоматически при первом запуске.

## 🧪 Тестирование

Проект сопровождается набором юнит-тестов. Для запуска всех тестов выполните:

```bash
pytest -v
```

**Что проверяют тесты:**

- **Валидацию модели `Vacancy`** (пустые строки, некорректные URL).
- **Логику вычисления средней зарплаты** и работу магических методов сравнения.
- **Корректность подключения к API hh.ru** и структуру возвращаемых данных.
- **Изолированную запись и чтение JSON** без создания дубликатов (с использованием фикстуры `tmp_path`).

## ⚠️ Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `ConnectionError: Не удалось подключиться к API hh.ru` | Проблемы с интернет-соединением или временный сбой на стороне hh.ru. | Проверить подключение к сети и повторить запрос через некоторое время. |
| `ValueError: Некорректный URL` | API вернул вакансию с невалидной ссылкой, которая не прошла валидацию в модели. | Ошибка обрабатывается автоматически: некорректная вакансия пропускается, программа продолжает работу. |
| `ModuleNotFoundError: No module named 'src'` | Команда запускается не из корневой папки проекта. | Перейти в корень проекта (`cd vacancies_from_hh`) перед запуском `python main.py`. |
| `⚠️ После фильтрации по ключевым словам вакансий не осталось` | Введённые ключевые слова не найдены в описаниях отобранных вакансий. | Проверить орфографию ключевых слов или расширить поисковый запрос. |
