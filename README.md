# Парсер вакансий с hh.ru

Курсовая работа по интеграции с API hh.ru.  
Позволяет искать вакансии, фильтровать по ключевым словам, сортировать по зарплате и сохранять результаты в JSON-файл.


## 🚀 Возможности

- Поиск вакансий по ключевому запросу
- Фильтрация по ключевым словам в описании
- Сортировка по убыванию зарплаты
- Сохранение в `vacancies.json` без дубликатов
- Человекочитаемый консольный интерфейс

## 🛠 Технологии

- Python 3.13+
- Poetry (управление зависимостями)
- `requests` — для работы с API hh.ru
- ООП, абстрактные классы, принципы SOLID
- JSON-хранилище
